# 에셋 넣는 방법 (3D 모델 · 효과음)

파일이 하나도 없어도 게임은 기본 도형(원기둥·원뿔)과 합성 효과음으로 실행됩니다.
아래 이름 규칙대로 파일을 넣고 브라우저를 새로고침하면 자동으로 바뀝니다.

## 3D 모델: `assets/models/`

GLB(바이너리 glTF) 파일만 사용합니다. Meshy, Tripo 등으로 만든 모델을 GLB 로 내보내 넣으세요.

| 파일 이름 | 바뀌는 대상 | 크기 맞춤 |
|---|---|---|
| `engineLifter.glb` | 1단 엔진 LV-200 | 높이 = 부품 길이 2.4 m |
| `engineVacuum.glb` | 2단 엔진 VX-60 | 높이 = 1.6 m |
| `tankLarge.glb` | 대형 연료탱크 | 높이 = 8.0 m |
| `tankSmall.glb` | 소형 연료탱크 | 높이 = 3.5 m |
| `decoupler.glb` | 단 분리기 | 높이 = 0.4 m |
| `capsule.glb` | 탑재물 캡슐 | 높이 = 2.2 m |
| `heavyPayload.glb` | 중량 화물 | 높이 = 3.0 m |
| `launchPad.glb` | 발사대 | 가로 지름 = 30 m (상판 지름) |
| `landingPad.glb` | 부스터 착륙 패드 | 가로 지름 = 80 m (착륙 지점 지름) |
| `planet.glb` | 멀리서 보이는 행성 구 | 전체 지름 = 행성 지름 (1,200 km) |

- 부품 파일 이름은 `src/config/physicsConfig.js` 의 `parts` 이름(부품 id)과 같아야 합니다. 부품을 새로 추가했다면 `<부품 id>.glb` 로 넣으면 됩니다.
- 모델의 **위쪽은 +Y 축**이어야 합니다 (glTF 기본). 부품은 기수 방향이 위, 엔진 노즐이 아래입니다.
- 크기와 위치는 자동으로 맞춥니다. 모델 원래 크기·원점과 상관없이 **높이(또는 지름)에 맞춰 비율을 유지한 채 확대·축소**하고, 바닥 가운데를 부품 아래 끝에 둡니다.
- 물리 계산(질량·추력·항력 단면적 등)은 설정 파일 값만 쓰며, 모델 모양은 영향을 주지 않습니다.
- 발사대 모델은 상판 높이를 3 m 로 만들어야 로켓이 상판 위에 정확히 섭니다 (물리상 상판 높이 3 m).
- 파일이 깨졌거나 읽지 못하면 브라우저 콘솔에 경고만 남기고 그 물체는 기본 도형으로 그립니다.

## 효과음: `assets/audio/`

| 파일 이름 (`.mp3`, `.ogg`, `.wav`) | 재생 시점 |
|---|---|
| `engine` | 엔진 소리 (반복 재생, 크기가 추력 비율을 따라감) |
| `liftoff` | 발사(이륙) 순간 |
| `stage` | 단 분리 |
| `explosion` | 기체 파손·폭발 |
| `landing` | 부스터 착륙 성공 |

- 없는 소리는 코드로 만든 합성음을 씁니다.
- 브라우저 자동 재생 제한 때문에 **첫 클릭이나 키 입력 후부터** 소리가 납니다.
- 미션 패널의 🔊 버튼으로 소리를 끄고 켤 수 있습니다.

## 파일 목록을 읽는 방식

게임은 `tools/serve.py`(또는 `python3 -m http.server`)가 보여주는 폴더 목록에서 실제로 있는 파일만 골라 불러옵니다.
그래서 없는 파일을 요청해 404 오류가 생기지 않습니다. 폴더 목록을 보여주지 않는 다른 웹 서버에서는 기본 도형·합성음으로 실행됩니다.
