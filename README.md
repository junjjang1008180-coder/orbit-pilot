# ORBIT PILOT (궤도 조종사)

맥북 브라우저에서 실행되는 HTML · JavaScript · Three.js 기반 3D 로켓 발사·비행 조종 시뮬레이터입니다.
빌드 도구 없이 ES 모듈로 동작하며, Three.js 는 `vendor/three` 에 포함되어 있어 인터넷 없이 실행됩니다.

## 실행 방법

```bash
python3 tools/serve.py
```

- 게임: <http://localhost:5173>
- 물리 테스트: <http://localhost:5173/tests/>

(`python3 -m http.server 5173` 로도 실행되지만, `tools/serve.py` 는 캐시를 꺼서 수정 사항이 바로 반영됩니다.)

## 현재 구현 단계

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 기본 장면(행성·발사대·임시 로켓), 추력·중력 물리 | 구현 |
| 2 | 키보드 스로틀·자세 조종, 추적 카메라(회전·확대), 기본 HUD | 구현 |
| 3 | 공기 밀도·항력, 동압·Max-Q 파손, 연료 소모(치올콥스키), 단 분리 | 구현 |
| 4 | 원지점·근지점 계산, 지도(궤도) 화면, 원궤도 진입 판정, 네비볼 | 구현 |
| 5 | 드래그 앤 드롭 로켓 설계 화면(TWR·Δv), 미션 선택·판정, 점수 | 구현 |
| 6 | 부스터 착륙 미니게임, GLB 모델 교체, 엔진 불꽃·폭발 효과, 효과음 | 구현 |

추가 기능: 튜토리얼 · 자동조종(자세 보조·자동 비행) · 우주 정거장 도킹 · 시간 가속 · 설계 저장·공유 코드 · 기동 노드 · 달과 궤도 전이 · 재진입 가열과 낙하산 회수 (아래 각 절 참고)

| `Z` / `X` | 스로틀 최대(엔진 점화) / 엔진 끄기 |
| `W` / `S` | 피치: 기수 내리기 / 올리기 (`W` 는 동쪽으로 기울임) |
| `A` / `D` | 요: 왼쪽 / 오른쪽 |
| `Q` / `E` | 롤: 반시계 / 시계 (꼬리에서 볼 때) |
| `Space` | 단 분리 (맨 아래 단을 떼어 냄) |

| `H`/`N` · `J`/`L` · `I`/`K` | RCS 평행이동: 앞/뒤 · 왼쪽/오른쪽 · 아래/위 |
| `U` | 우주 정거장에서 분리 |
| `P` | 낙하산 펼치기 |
| `.` / `,` | 시간 가속 올리기 / 내리기 (×1·2·5·10·50·100·1000) |
| 우클릭 드래그 | 카메라를 로켓 주위로 회전 (Mac 트랙패드: 두 손가락 클릭 후 드래그) |
| 마우스 휠 | 확대 / 축소 |

- 왼쪽 위 미션 패널: 미션 목표·진행 상황·결과, `재시작` / `설계로` 버튼.
- 저고도에서 최대 스로틀로 곧장 올라가면 Max-Q(15 kPa)를 넘어 파손됩니다. 동압 막대를 보며 스로틀을 조절하세요.
- 지면에 서 있는 동안에는 자세가 바뀌지 않습니다.
- 네비볼: 가운데 노란 표시 = 기수, 녹색 원 = 진행 방향, 빨간 X = 역방향, 노란 □ = 착륙 지점 방향. 파랑 = 하늘, 갈색 = 땅.
- 미션 패널 🔊 버튼: 소리 켜기/끄기 (소리는 첫 클릭·키 입력 후부터 납니다).

## 부스터 착륙 미니게임

1. 비행 중 `Space` 로 1단을 분리하면 그 단이 **부스터**가 됩니다. 분리 순간 부스터가 조종 없이 떨어질 지점(중력+공기저항 계산)에 **착륙 지점**(노란 X 패드, 노란 빛기둥)이 생깁니다.
2. `B` 로 부스터 조종으로 바꿉니다. 같은 키(Shift/Ctrl/Z/X/W/S/A/D/Q/E)로 조종합니다. 다시 `B` 로 로켓으로 돌아갑니다 (로켓의 스로틀은 그대로 유지).
3. 왼쪽 착륙 안내 상자에서 착륙 지점까지 거리·방위, 하강 속도·수평 속도·기울기를 기준과 비교하며 내립니다.
4. 땅에 닿는 순간 **수직 속도 ≤ 6 m/s, 수평 속도 ≤ 3 m/s, 기울기 ≤ 10°** 를 모두 만족하고 **착륙 지점 40 m 안**이면 성공입니다. 속도·기울기를 넘으면 폭발, 안전해도 지점 밖이면 실패입니다 (`physicsConfig.js` 의 `landing`).
- 요령: 재진입 중 동압이 15 kPa 를 넘으면 부스터가 부서집니다. 동압 막대가 오르면 역방향(빨간 X)으로 엔진을 켜 감속하세요. 연료를 남기려면 1단 연료가 30~40% 남았을 때 분리하세요.
- 로켓 본체도 같은 기준보다 세게 땅에 부딪히면 파손됩니다.

## 자동조종

- **자세 보조(`T`)**: 기수 방향만 잡아 줍니다. 자세 유지 중에도 조종 키로 돌릴 수 있고, 키를 떼면 그 자세를 유지합니다. 스로틀은 직접 조절합니다.
- **자동 비행(`G`)**: 자세·스로틀·단 분리까지 맡습니다.
  - 로켓: 점화 → 동압 관리(한계의 70% 위면 스로틀 낮춤) → 중력 선회(1→41 km, 최대 80°) + 원지점까지 남은 시간 피드백(추력이 약하면 기수를 들고, 너무 가파르면 더 눕힘) → 자동 단 분리 → 원지점 85 km → 원궤도 연소 시간의 절반 전부터 수직 속도를 0 으로 붙잡으며 원궤도 연소 → 완료 후 자세 보조를 진행 방향으로. 공기가 진할 때는 기수를 진행 방향 9° 안에 둡니다(고도를 잃는 중이면 더 들 수 있음). Δv 가 모자라면 멈추고 이유를 알려 줍니다.
  - 부스터 착륙 미션: 자동 궤도 진입이 1단 연료를 35% 남기고 분리하고, 부스터는 스스로 자동 착륙을 시작합니다(`B` 로 지켜보기).
  - 부스터(`B` 로 조종 중): 높은 곳에서 착륙 지점까지 닿는 만큼만 수평 속도를 줄이고(동압은 전체 속도 기준) → 고도 약 50 m 에서 착륙 지점 위로 접근 → 수직 착륙. 연료 없이 떼어 낸 부스터는 착륙할 수 없다고 알려 주고, 공중에서 부서지면 착륙 실패로 기록합니다.
  - 정거장 20 km 안: 자동 도킹 (아래 참고)
- 조종 키(자세·스로틀·Z/X·RCS 평행이동)를 누르면 자동 비행이 바로 해제되고, `G` 로 끄면 엔진도 꺼집니다. ⌘ 를 누르면 눌린 키를 모두 풀고(macOS 는 ⌘ 를 누른 동안 키를 뗀 신호를 보내지 않음), Ctrl·Option 과 함께 누른 동작 키(예: 한/영 전환 Ctrl+Space)는 게임 동작으로 보지 않습니다.
- 자동조종도 사람과 같은 입력·같은 물리를 씁니다. 조정값은 `physicsConfig.js` 의 `autopilot`.

## 시간 가속

- `.` 로 올리고 `,` 로 내립니다. 오른쪽 아래 **⏩ 시간 ×N** 표시에 지금 배속과 한계가 보입니다.
- 물리는 그대로 1/120 s 간격으로 돌고, 한 프레임에 여러 스텝을 계산합니다 (빨리 감기일 뿐 정확도는 같습니다).
- 한계: 대기 안 ×10, 엔진·RCS 가동 중 ×5, 천체(행성·달) 표면에서 150 km 안 ×100, 그 외 ×1000 (`physicsConfig.js` 의 `timeWarp`). 한계가 내려가면 자동으로 낮춰졌다가, 다시 올라가도 저절로 올라가지는 않습니다.
- 단 분리·파손·착지·도킹·중력권 변경(달 중력권 진입·이탈)·미션 결과 같은 사건이 생기면 ×1 로 돌아옵니다.

## 설계 저장·공유

- 설계 화면 **내 설계** 에서 이름을 붙여 저장하고(같은 이름은 덮어쓰기), 목록에서 불러오기·삭제할 수 있습니다. 저장은 이 브라우저(localStorage)에만 남습니다.
- **공유 코드**: `OP1-` 로 시작하는 문자열을 복사해 다른 사람에게 주면, **가져오기** 에 붙여 넣어 같은 설계를 만들 수 있습니다. 모르는 부품이 있거나 깨진 코드는 이유를 알려 주고 거절합니다.
- 마지막으로 작업한 설계는 새로고침해도 자동으로 복원됩니다.

## 기동 노드 (궤도 계획)

1. 궤도에 오르면 왼쪽 **🧭 기동 계획** 상자에서 **원지점에 노드** / **근지점에 노드** 를 누르거나, 지도(`M`)에서 궤도선을 클릭해 그 지점에 노드를 만듭니다.
2. 조절 단위(1·10·100 m/s)를 고르고 **진행·법선·방사** Δv 와 **시각**을 `−`/`+` 로 바꿉니다. 지도에 실행 후 궤도가 점선으로 보이고, 상자에 Δv 합계·연소 시간·실행 후 원지점/근지점이 나옵니다.
3. **자동 실행**(또는 `G`): 노드 방향으로 자세를 돌리고, 연소 시간의 절반 전에 점화해 남은 Δv 가 0 이 될 때까지 밉니다 (끝 무렵 스로틀을 줄여 정확히 멈춤). 시간 가속 중이면 점화 10초 전에 ×1 로 돌아옵니다.
- 직접 하려면 `T` 로 자세 보조를 **기동 방향**에 두고(네비볼의 파란 □), 점화 시각에 엔진을 켜세요.
- 예측은 케플러 2체 궤도(공기저항 없음)로 계산합니다. 연소 시간은 치올콥스키 식, 현재 단 연료가 모자라면 경고합니다.

## 달과 궤도 전이

- 달: 반지름 150 km, 표면 중력 1.62 m/s², 행성 중심에서 4,000 km 거리의 원궤도를 약 7.4시간에 한 바퀴 돕니다(발사 궤도와 같은 면·같은 방향). 대기는 없고 자전하지 않습니다.
- **중력권 이어 붙이기**: 달 중심에서 약 642 km(중력권, `a·(μ달/μ행성)^0.4`) 안에서는 달 중력만, 밖에서는 행성 중력만 받습니다. 그래서 각 중력권 안의 궤도는 케플러 예측과 그대로 맞습니다.
- 달 중력권에 들어가면 고도·속도·원지점·근지점·네비볼·자세 보조(진행 방향)·지도 카메라가 모두 **달 기준**으로 바뀌고, HUD 고도 옆에 「달 기준」 표시가 붙습니다. 기동 노드는 중력권이 바뀌면 지워집니다.
- **달 조우 예측**: 지금 궤도(또는 기동 노드 실행 후 궤도)가 달 중력권에 들어가면 HUD 「달 조우」 줄과 지도에 조우 지점까지의 궤도선, 조우 순간의 달(반투명)과 달 기준 경로·근접 고도가 보입니다.
- 순서 (예시 설계 **달 탐사 로켓 (3단)** 추천):
  1. `G` 로 자동 궤도 진입 → 기동 계획 **🌕 달 전이 계획**: 달 근접 고도가 30 km 가 되는 시각·진행 Δv(약 700 m/s)를 자동으로 찾아 노드를 만듭니다 → `G` 로 실행, `.` 로 시간 가속.
  2. 연소 오차로 근접 고도가 어긋나면 같은 버튼(**🌕 달 근접 보정**)으로 2분 뒤 작은 보정 노드를 만듭니다.
  3. 달 중력권에 들어가면 **원궤도 만들기**(쌍곡선이면 근지점에서 감속) → `G`.
  4. 달 궤도에서 `G` = **자동 달 착륙**: 수평 속도를 없애고, 제동 곡선을 따라 내려와 마지막 40 m 는 1.5 m/s 로 수직 착지합니다. 착지 기준은 행성과 같습니다(수직 6 m/s · 수평 3 m/s · 기울기 10°).
- 달 표면에 선 비행체는 달과 함께 움직이며, 추력이 달 중력보다 크면 다시 이륙할 수 있습니다.
- 미션: **달 근접 비행**(달 중력권 진입) · **달 궤도 진입**(근지점 5 km 이상, 원지점이 중력권 안) · **달 착륙**(안전 착지).
- 그래픽: 충돌구·바다 무늬의 달(코드로 그린 텍스처), 달 20 km 아래에서는 비행체 아래에 고해상도 지표 조각, 달 근처에서는 행성광과 보조광으로 밤쪽도 보입니다.
- 새 부품: 2단 엔진 VX-120(120 kN), 대형 1단 엔진 LV-450(450 kN), 착륙 엔진 LM-15(15 kN, 달에서 조절하기 쉬운 작은 추력).

## 재진입 가열과 낙하산 회수

- **가열**: 공기 속을 빠르게 지나면 앞면이 뜨거워집니다. 열유속 q̇ = k·√(ρ/r)·v³ (Sutton–Graves 식)으로 표면 온도를 올리고, 우주에서는 복사(εσT⁴)로 식습니다. 축소 행성은 궤도 속도가 실제의 약 1/3 이라 열이 너무 적으므로 k 에 게임 배율 8 을 곱했습니다 (`physicsConfig.js` 의 `heating`).
- **열 차폐막**: 붙어 있는 맨 아래 부품이 열 차폐막이고 꼬리가 진행 방향을 향하면(역진행에서 40° 안) 열 차폐막이 열을 받아 3,000 K 까지 버팁니다. 아니면 가장 약한 부품의 한계(캡슐 1,400 K · 낙하산·탱크 1,300 K 등)를 넘는 순간 기체가 탑니다. 뭉툭한 열 차폐막이 앞이면 항력 계수도 커져(1.2) 높은 곳에서 먼저 감속합니다.
- **낙하산(`P`)**: 공기 기준 350 m/s 이하, 동압 12 kPa 이하에서 펼쳐야 하고, 더 빠르면 찢어집니다. 처음에는 보조 낙하산(25 m²)만 펴지고 고도 1.5 km 아래에서 400 m² 로 다 펼쳐집니다. 펼친 동안 기체는 낙하산 아래로 매달려 똑바로 서고, 1톤 캡슐은 해수면에서 약 5.5 m/s 로 내려옵니다(착지 기준 6 m/s).
- **자동 재진입·회수(`G`, 궤도에서 낙하산이 있을 때)**: 역추진으로 근지점 30 km → 열 차폐막·낙하산 단만 남기고 분리 → 꼬리를 앞세워 재진입 → 충분히 느려지면 낙하산 → 착지.
- HUD: 뜨거울 때 「표면 온도 (현재 / 한계, 열 차폐막 여부)」, 낙하산이 있으면 「낙하산」 상태 줄. 한계의 80% 를 넘으면 과열 경고. 화면에는 앞면의 충격파 빛과 뒤로 흐르는 플라스마 꼬리, 펼친 낙하산(주황·흰 줄무늬)이 보입니다.
- 미션 **궤도 왕복 (재진입·낙하산 회수)**: 원궤도에 오른 뒤 행성에 안전하게 착지하면 성공. 예시 설계 **회수 캡슐 로켓 (3단)** = 1단 → 2단(궤도 진입·역추진) → 열 차폐막 + 캡슐 + 낙하산.
- 열 차폐막 없이 기수부터 들어가면 저궤도 재진입에서도 탑니다. 달에서 돌아오는 속도(약 2.9 km/s)도 열 차폐막이면 버팁니다(최고 약 2,000 K).

## 도킹

1. 미션 **우주 정거장 도킹** 을 고르고(맨 위에 캡슐 = 도킹 포트 필요) 발사하면, 고도 85 km 원궤도에 우주 정거장이 생깁니다. 같은 로켓으로 자동 궤도 진입을 미리 계산해, 궤도에 오른 순간 정거장이 약 3 km 앞에 있도록 발사 순간 기준으로 배치합니다.
2. 궤도에 오르면 왼쪽 **목표 안내**(포트까지 거리·상대 속도·접근 속도·정렬·축 이탈)와 네비볼의 자주색 ○(정거장 방향)·하늘색 ○(상대 진행)를 보며 다가갑니다. 지도 화면에는 정거장과 그 궤도선(자주색)이 보입니다.
3. 가까이서는 `R` 로 RCS 를 켜고 `H/N·J/L·I/K` 로 기체를 돌리지 않고 밀어 맞춥니다. 정거장 포트는 진행 반대 방향을 향합니다.
4. 포트 사이 **1 m 이내, 상대 속도 0.5 m/s 이하, 정렬 10° 이하**면 결합(운동량 보존)되고 미션 성공. 포트 근처에서 2 m/s 넘게 부딪히면 파손됩니다. `U` 로 분리(0.3 m/s 로 밀어냄).
- **자동 도킹(`G`)**: 접근(먼 거리는 주 엔진, 가까우면 RCS) → 포트 앞 30 m 정렬 → 포트 축을 따라 접근(가까울수록 느리게, 닿기 직전 0.3 m/s). 기본 2단 로켓 기준 궤도 진입 후 약 4분, 연료 약 70 kg.

## 튜토리얼

설계 화면 오른쪽 위 **📘 튜토리얼** 버튼(처음 방문하면 권유 카드도 뜸)으로 시작합니다.

각 단계는 실제 조작·비행 상태를 감지해 자동으로 넘어가고, 설명하는 화면 요소는 노란 테두리로 강조됩니다.
기체가 부서지면 재시작을 권하고, 재시작하면 점화 단계부터 다시 안내합니다. 언제든 `이 단계 건너뛰기` / `튜토리얼 끝내기` 를 누를 수 있습니다.

## 물리 모델 요약

- 단위: SI (m, kg, s, N). 좌표: 행성 중심 관성 좌표계, 행성 자전 없음.
- 축소 행성: 반지름 600 km, 지표 중력 9.81 m/s², μ = g·R².
- 중력: g = μ / r², 행성 중심 방향. 달 중력권 안에서는 달 중력 + 달의 궤도 가속도(달 기준 2체 운동).
- 추력: 기수 방향. 연료 소모율 ṁ = F / (Isp·g₀), 스텝마다 Δv = Isp·g₀·ln(m₀/m₁) (치올콥스키).
- 대기: ρ(h) = ρ₀·e^(−h/H) (ρ₀ = 1.225 kg/m³, H = 5.6 km, 70 km 위는 진공).
- 항력: D = ½ρv²·Cd·A (상대 속도 반대), 동압 q = ½ρv². q 가 한계를 넘으면 기체 파손.
- 궤도: ε = v²/2 − μ/r, h⃗ = r⃗ × v⃗, e⃗ = (v⃗ × h⃗)/μ − r̂, a = −μ/2ε, 근지점 a(1−e), 원지점 a(1+e) (ε ≥ 0 이면 탈출 궤도).
- 원궤도 진입 성공: 근지점 ≥ 70 km 이고 이심률 ≤ 0.02 (설정 파일 `orbit`). 비행 중 한 번 만족하면 기록.
- 단 분리: 아래 단의 건조 질량+남은 연료 제거, 운동량 보존하며 1.5 m/s 로 분리, 분리 단은 중력·항력만 받는 독립 물체.
- 착지: 수직 속도·수평 속도·기울기를 각각 기준과 비교, 넘으면 폭발(파손).
- 재진입 가열: q̇ = k·√(ρ/r)·v³, C·dT/dt = q̇ − εσ(T⁴ − T∞⁴). 앞면 부품의 최고 온도를 넘으면 파손.
- 낙하산: 항력 ½ρv²·Cd·A 를 더하고, 펼친 동안 기수를 진행 반대 방향으로 돌린다.
- 분리된 단도 로켓과 같은 물리(추력·연료·자세·항력·Max-Q·착지)로 움직이는 독립 비행체.
- 고정 간격(1/120 s) 도약법(leapfrog) 적분: 중력은 스텝 처음·끝에 절반씩, 추력·항력·RCS 는 처음에. 궤도 에너지가 오래 보존되어 케플러 예측과 600초 동안 2 m 안으로 맞습니다.
- 궤도 예측: 범용 변수 케플러 전파(타원·포물선·쌍곡선 공통).
- 지면 위에서는 위쪽 알짜 가속도가 0 이하(TWR ≤ 1)이면 움직이지 않습니다.
- 화면은 로켓 위치를 원점으로 옮겨 그려(floating origin) 큰 좌표의 정밀도 문제를 피합니다.
